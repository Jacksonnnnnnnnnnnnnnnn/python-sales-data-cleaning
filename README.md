# Sales Data Cleaning Automation

## Overview

This project cleans and processes sales data
from multiple CSV files using Python and Pandas.

## Features

- Merge multiple CSV files
- Remove duplicate orders
- Clean product names
- Calculate total sales by product
- Export cleaned data and summary reports

## Technologies

- Python
- Pandas

## How to use

- open main.ipynb on jupyter notebook on your VScode or Google Colab
- click 'Run all' and then you will got cleaned_orders.csv and sales_by_product.csv

## Limitations

- Only supports CSV files
- There is no GUI or web. Required to install Python and Pandas to run locally
- Conflicting duplicate must review manually
